Solve this task in the ReAct format, alternating Thought, Action and Observation steps.

Write one Thought and one Action per step, for example:
Thought 1: ...
Action 1: user_ratings[]
The Observation is then returned to you. Use at most 5 tools, then finish with "Action
  N: Finish[r]".

def reflection_prompting(true_rating, user_prompt, model_response):   # Fig. 5, verbatim apart from the prints
    reflection_prompt = "The following is a previous prediction you made to a given prediction request.\n\n"
    reflection_prompt += "##User Prompt##\n\n"
    reflection_prompt += user_prompt.replace("[/INST]", "").replace("[INST]", "") + "\n"
    reflection_prompt += "##Your Response##\n"
    reflection_prompt += model_response + "\n"
    reflection_prompt += "The true rating is " + str(true_rating) + ". It's clear that you're not predicting well, so learn the rules and reflect on why you didn't predict well.\n"
    reflection_prompt += "So can you reflect on why you are not predicting accurately? Think about the rules, summarize them, and answer a new improving question.Here, I will provide you with a new prediction prompt.\n\n"
    return reflection_prompt
